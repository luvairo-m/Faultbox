## Порядок и критерии выполнения

Задачи выполняются в указанном порядке: результат предыдущей задачи служит основой для следующей. Для шаблонов `init` необходимы готовые загрузка файлов и `check`; интеграция выполняется после подробного журнала. Буквенные суффиксы сохранены для стабильной нумерации, поэтому отдельные пункты идут не по алфавиту.

Каждая задача включает относящиеся к ней проверки, поддержку типов и актуализацию документации. Тестирование проводится вместе с реализацией, а финальная приёмка проверяет их совместную работу.

Учебные требования распределены по задачам: осмысленное использование `list`, `tuple`, `dict`, `set`, генератора, собственного обрабатываемого исключения и контекстного менеджера; проверка типов mypy, тесты pytest, упаковка через `pyproject.toml` и установка через pip.

В объём входят все семь расширений: `body_file`, `reset`, подробный журнал, `verify`, условия по заголовкам/query, изоляция `X-Test-Case-ID` и `init`. Условия по телу запроса, regex/JSONPath, прокси, TLS, база данных, веб-интерфейс и случайные сбои не запланированы.
